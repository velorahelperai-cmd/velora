## Velora Workspace — design foundations (2026-11-02)

The owner asked for a named, consistent system and clarified that the page background stays white, with cards in another shade of white. This is the working specification, not a claim that all pages already conform. The supplied inbox image informs the column hierarchy and compact controls; exact values below are Velora decisions, not sampled Trengo values. A generated image was used to explore the composition and includes illustrative content that is not an implemented feature.

- **Canvas and surfaces:** page `#ffffff`, card `#fafbfc`, subtle surface `#f4f7f8`, borders `#e2e7eb`. Keep semantic message colors distinct. The narrow dark navigation rail remains the explicitly requested navigation treatment.
- **Type:** the existing locally hosted Tajawal is used for Arabic and English. Main text `#172126`, secondary text `#5f6b76`; use clear page, section and body hierarchy, with wrapping and RTL/LTR support.
- **Controls:** teal `#0f766e` for primary actions, darker hover, white secondary controls with a fine border, consistent rounded corners and visible keyboard focus. Targets should generally be at least 44px.
- **Structure:** compact navigation, a clear page heading, aligned columns and restrained dividers. Inbox places the conversation list beside the main chat, with details available contextually; collapse columns responsibly at smaller widths. Cards should not be nested unnecessarily.
- **States and messages:** info, success, warning and error each get a consistent compact bordered surface, readable contrast and their own semantic color. Preserve the actual message and any available recovery action. Empty and loading states are clearly worded and never presented as success; apply this intentionally to individual screens rather than treating every live status as an error.
- **Scope and verification:** workspace and owner administration only. Preserve all existing actions, permissions, data and message semantics. Responsive, contrast and browser checks must be recorded per area; this specification alone does not establish coverage.
